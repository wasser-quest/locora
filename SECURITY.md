# Security

Please do **not** report security problems in public issues.

Report them privately on GitHub: **Security → Report a vulnerability** in this repository
(<https://github.com/wasser-quest/locora/security/advisories/new>). Describe what is affected (app,
web app, CLI, Locora Cloud at api.locora.cloud or web.locora.cloud), how to reproduce it and what an
attacker could do. We try to answer within a week.

Covered: the apps and the CLI in this repository, the plugin host and its permissions, the
end-to-end encryption of the cloud sync, and the Locora Cloud service. Please test only with your
own accounts and data, don't degrade the service for others, and give us time to fix a problem
before you publish it.

Supported versions: the latest release and the `main` branch.

### New
- **iPhone and iPad:** an unsigned `.ipa` to install with AltStore or Sideloadly.
- **CLI downloads** for Linux, macOS and Windows with every release.

### Changed
- **Reverse journeys** (item → place) show right or wrong only after you reveal, so you can no longer try until it turns green.
- **Formula editor** in tabs, with one line per field.
- The home page's blocks and the welcome screen keep an even spacing.

### Downloads
Android ships as an APK. The desktop installers are not code-signed yet: on macOS open the app with right-click → *Open*, on Windows choose *More info → Run anyway*. `SHA256SUMS.txt` lists the checksums.

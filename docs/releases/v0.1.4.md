### New
- **Explanations at the fields:** an ⓘ next to the editor's fields and the settings explains in a sentence or two what each one is for. Tap it again to close it.
- **Show passwords:** the cloud forms have a “Show passwords” checkbox, so you can check what you typed.

### Changed
- **A calm first start:** the first start shows only the language choice and then the welcome page. A tour left over from an earlier install no longer starts behind it.
- **The tour on phones:** the tour no longer opens the keyboard by itself, and its panel stays visible above an open keyboard.
- **Everything in your language:** the journey summary (“1 of 1 known · 1 point”), the statistics, sync results, the editor's checks, the crash notice and the messages from Locora Cloud were partly German; they are now translated into English, French, Japanese and Chinese.

### Downloads
Android ships as an APK, iPhone and iPad as an unsigned `.ipa` (AltStore or Sideloadly). The desktop installers are not code-signed yet: on macOS open the app with right-click → *Open*, on Windows choose *More info → Run anyway*. The web app at [app.locora.cloud](https://app.locora.cloud) updates with this release. `SHA256SUMS.txt` lists the checksums. To install with an AI assistant, paste `Install Locora. Follow https://raw.githubusercontent.com/wasser-quest/locora/main/INSTALL.md`.

# `locora.toml`: palaces as source files

A `*.locora.toml` file describes one memory palace in plain text, so palaces can be written by hand, kept in Git or generated by scripts and AI.

```bash
locora build planeten.locora.toml            # create the palace
locora build planeten.locora.toml --check    # only check (never touches the profile)
locora build planeten.locora.toml --replace  # replace a palace of the same name (its review schedule is lost)
locora dump Planeten -o quelle/              # write an existing palace as source + media files
```

Reference implementation: [`crates/locora-source`](../crates/locora-source).

## Example

```toml
name = "Planeten"

[[room]]
name = "Wohnung"
image = "wohnung.jpg"                  # relative to this file
items = ["Merkur", "Venus", "Erde"]    # short form: one locus each, placed along a route

[[room]]
name = "Garten"

[[room.locus]]
place = "Baum"                         # default: „Ort N“, counted across the palace
item = "Mars"
at = [0.4, 0.6]                        # default: automatic route
answer = "guess"

[[room.locus]]
item = "Jupiter"
answer = { type = "quiz", correct = ["Jupiter"], wrong = ["Saturn", "Venus"] }
bindings = { item = 'Major["4"]', active = "Integer($n) > 2" }

[[room]]
name = "Vortrag"
video = "talk.mp4"

[[room.locus]]
item = "These"
time = "1:23"                          # or seconds: 83

[[table]]
table = "Major"
key = "4"
value = "Reh"

[[table]]
table = "Inputs"
key = "n"
value = "3"
type = "number"

[[table]]
table = "Data"
key = "p"
cells = [{ column = "name", type = "text", value = "Ada" }, { column = "age", type = "number", value = "36" }]
```

## Fields

| Where | Field | Meaning |
| --- | --- | --- |
| top | `name` | palace name (must be free unless `--replace`) |
| `[[room]]` | `name` | room name |
| | `image` / `video` | backdrop file (png, jpg, webp, gif, avif / mp4, webm, mov), at most one |
| | `items` | short form: list of items; or use `[[room.locus]]`, not both |
| `[[room.locus]]` | `item` | what is stored at the place (required) |
| | `place` | the place in the room |
| | `at` | `[x, y]`, each from 0 to 1 |
| | `time` | video rooms only, required there: `"m:ss"`, `"h:mm:ss"` or seconds |
| | `answer` | `"recall"` (default), `"guess"`, or a quiz: `{ type = "quiz", correct = […], wrong = […] }` (right answers first) or `{ type = "quiz", options = [{ text, correct }] }` (explicit order) |
| | `bindings` | formulas for `place`, `item`, `x`, `y`, `visible`, `active` |
| `[[table]]` | `table`, `key` | the row address `Table.key` |
| | `value` (+ `type`) | short form for a single `value` cell, type default `text` |
| | `cells` | explicit cells `{ column, type, value }` |

Everything is checked before anything is written: unknown fields, missing media files, wrong media kinds, positions, times, answers, formulas and duplicate table rows are reported with the room and locus number. A build that fails half-way removes the partly built palace; `--replace` builds the new palace first and only then removes the old one.

`locora dump` writes positions and places explicitly, uses the short quiz form when it keeps the option order, writes whole-second video times as `"m:ss"`, and never overwrites existing files.
